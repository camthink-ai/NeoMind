# ADR-0017:BuildCard/build_meta 移除

## 状态
生效(2026-09;功能自 2026-05 存在,四个月零观察使用)

## 背景
"AI Build Mode"结果卡片被埋在两层折叠抽屉里(工具卡→工具行展开),仅写类 CLI 命令触发;实现付出三处字符串耦合(Rust↔TS 手抄类型、前端硬编码路由表、后端生成 undo shell 字符串,widget 撤销甚至是 `rm -rf`)。

## 决策
整链移除:前端卡片/解析/类型/穿线/i18n,后端 BuildMeta 结构、CliResponse.build_meta、14 处构造。CLI 命令本体与进程内分发保留 —— 聊天驱动构建能力不变,结果回落为标准 JSON 展示。

## 后果
+ 净减 ~600 行,消三处耦合;零可观察行为变化(wiki 从未承诺,无人见过该 UI)。
- 若未来重提"聊天构建",从 git 历史可完整复活;复活时应以本 ADR 记录的耦合教训为设计约束。
