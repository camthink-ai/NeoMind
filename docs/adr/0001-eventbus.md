# ADR-0001:EventBus 发布/订阅作为子系统脊柱

## 状态
生效(项目初始架构)

## 背景
设备接入、agent 执行、规则触发、消息通知、数据推送等子系统需要协作。直调会造成网状依赖,单机边缘场景还需要松耦合以支持按需加载。

## 决策
全部子系统经 `neomind_core::eventbus` 的 EventBus 通信(pub/sub),禁止跨子系统直接函数调用。事件类型集中在 `EventType` 枚举(`neomind-core/src/event.rs`)。

## 后果
+ 新子系统(如 data-push)接入零侵入;单点事件可被多消费者复用(遥测→规则+仪表盘+推送)。
- 事件契约演化需集中改枚举;调用链路在代码里不可静态追踪,排查依赖日志与事件名。
