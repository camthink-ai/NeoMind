# ADR-0013:OpenAPI 全覆盖 + 漂移守卫进 CI

## 状态
生效(0.9.24 完成)

## 背景
API 文档曾与实现漂移:路由缺注解、100 个悬空 $ref、15 个 404 被报成 500 —— 第三方按文档生成的客户端直接坏。

## 决策
全部 334/338 handler 带 `#[utoipa::path]` 注解(4 个通配路由例外,文档言明);136 个 schema 注册齐;CI 以 router 验证过的路由索引跑漂移测试,新路由漏注解即红。

## 后果
+ 规格可导入 Apifox/openapi-generator;契约回归有机器守卫。
- 每个 handler 多 10-20 行注解样板 —— 用生成友好性换来的,接受。
