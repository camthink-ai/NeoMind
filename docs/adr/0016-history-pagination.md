# ADR-0016:会话历史分页(raw-index 游标 + 碎片守卫)

## 状态
生效(2026-09)

## 背景
会话历史全量加载:长会话首屏慢、DOM 无上限增长,低端设备滚动卡顿。

## 决策
`GET /sessions/{id}/history` 可选 `limit`+`before`(原始记录索引、排他游标),返回 `total`/`has_more`;无参数行为不变。分页起点若落在 assistant 回合的碎片组中间(一个回合存 3 条相邻记录),自动回退到上一条 user 消息。前端默认载最新 200 条,"加载更早"向上翻页并锚定滚动位置。游标锚定在初始快照,尾部追加不漂移。

## 后果
+ 首屏与 DOM 有界;碎片组永不被拆(前端 merge 语义保持)。
- 游标按"追加不改写"假设成立;若未来支持编辑历史,需改时间戳游标。
