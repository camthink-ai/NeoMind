② 新增 / 编辑智能体 —— 连续表单流（顺序 = 身份 → 能力 → 运行策略）

无向导的单页连续表单（遵循 DESIGN_SPEC：无满宽分隔线、无装饰性分区头），仅以顺序表达分组：身份（名称/描述/模型）→ 能力（类型卡 + 指令 + 输出字段 + 护栏折叠行）→ 运行策略（节奏/通知 + 高级折叠，按类型过滤）。配置面与确定性成正比：自由模式只剩一句话+节奏，确定性模式的旋钮全部折叠在默认值后。解决四个混乱来源：输出区插在模式卡与基本信息之间、调度区离模式区太远、高级项不随模式变化、试跑按钮埋在表单中部（改为吸底 CTA）。保留 · 新增 · 调整（含位置重排）。

③ 判定链详情 —— "为什么行动，一眼可查"

通知点开后的详情页（002 §3.2/§4.5）。多源判定链展示"它看到了什么、为什么行动"，已执行联动如实回显；人工动作只有反馈（标记误报/确认有效）——不设认领、派单等业务流程（"处置台"已移出设计：现有系统无此逻辑，平台不做业务流转）。
