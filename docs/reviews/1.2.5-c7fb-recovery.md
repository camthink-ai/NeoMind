```sh
EVAL_CHAT_TIMEOUT=120 .venv/bin/python eval/run_eval.py regression \
  --regression-set eval/regression_set_c7fb_smoke.txt --lang both --rounds 1 \
  --run-dir /tmp/neomind-recovery-smoke

  --regression-set eval/regression_set_c7fb_recovery.txt --lang both --rounds 3 \
  --baseline /path/to/fresh-matched-baseline/scores.jsonl \
  --run-dir /tmp/neomind-recovery-paired
```

需要查看未被识别的模型正文时，可在受控复现进程启用：

```sh
RUST_LOG='info,neomind_agent::agent::streaming::stream_core=trace,neomind_agent::llm_backends::backends::llamacpp=debug'
```

Trace会包含模型正文/思考片段，可能带业务数据，只用于显式开启的本地诊断；分享前检查内容。正常日志只保留请求参数、逐轮内容长度和native/解析数量。计时告警现在按本轮计算，不再把前面轮次的时间算进当前思考。

验收需同时报告新损失恢复、保留用例损失、实际副作用状态、耗时、失败原因和整体净变化；没有真实模型结果前不宣称回归已治愈。
